# AI Learning Assistant

An AI-powered learning platform with separate spaces for technical and non-technical learning.

## Features

### Technical Space
- Code Explainer: Understand any code snippet
- Debug Assistant: Find and fix bugs faster
- Documentation Helper: Generate or understand docs
- Architecture Guide: Design better systems

### Non-Technical Space
- Concept Simplifier: Break down complex ideas
- Personal Tutor: Learn any subject step-by-step
- Knowledge Organizer: Summarize and organize information
- Skill Builder: Create personalized learning paths

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```
